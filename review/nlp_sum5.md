# 대화 요약 모델 개발 및 강화학습 기반 자동 개선 시스템 구현

## 1. 초기 목표
- dialogue를 요약했을 때 summary와 동일한 값을 가지도록 훈련시키는 시스템 개발
- Rouge 점수를 기반으로 모델의 성능을 평가하고 개선하는 방법 구현

## 2. 개발 과정

### 2.1 기본 요약 모델 구현
- BART 모델을 기반으로 한 sequence-to-sequence 학습 구현
- dialogue를 입력으로 받아 summary를 생성하도록 설계
- Rouge 점수를 사용한 기본적인 성능 평가 시스템 구축

### 2.2 자가 개선 시스템 도입
- 초기에는 단순한 Rouge 점수 기반 평가에서 더 발전된 자가 개선 시스템을 구현
- 주요 구현 기능:
  - 품질 평가: Rouge 점수 기반 평가
  - 오류 분석: 요약문 길이, Rouge 점수, 핵심 정보 누락 여부 확인
  - 개선 제안: 분석된 문제점 기반 구체적 개선 방안 제시
  - 자동 파라미터 조정: 제안된 개선사항 기반 모델 파라미터 자동 조정
  - 개선 이력 관리: 변경사항과 개선 과정 로깅

### 2.3 강화학습(PPO) 도입
- 과적합을 허용하면서 Rouge 점수를 최대화하는 방향으로 발전
- PPO(Proximal Policy Optimization) 알고리즘 구현:
  - 안정적인 정책 최적화
  - 클리핑된 목적 함수로 급격한 정책 변화 방지
  - 엔트로피 보너스를 통한 탐색 장려
- Rouge-1, Rouge-2, Rouge-L의 평균이 50점 이상이 될 때까지 학습하도록 설정

### 2.4 멀티 GPU 지원 및 성능 모니터링 개선
- torch.nn.DataParallel을 사용한 멀티 GPU 학습 지원
- 검증 데이터셋(test.csv)을 기준으로 한 성능 모니터링 시스템 구현
- 최고 성능 모델 자동 저장 및 로깅 시스템 구축

## 3. 시행착오 및 해결 방안

### 3.1 성능 평가 기준 변경
- 초기: 훈련 데이터셋 기반 평가
- 문제점: 실제 성능을 정확히 반영하지 못함
- 해결: 검증 데이터셋(test.csv)을 기준으로 성능 평가하도록 변경

### 3.2 PPO 구현 관련 이슈
- 문제점: 
  - 불안정한 학습 과정
  - GPU 메모리 관리 문제
- 해결:
  - 클리핑된 목적 함수 도입
  - 배치 처리 최적화
  - 엔트로피 보너스 조정

### 3.3 멀티 GPU 환경 대응
- 문제점: 
  - 모델 저장/로드 시 GPU 관련 오류
  - 데이터 분배 비효율
- 해결:
  - DataParallel 구현 개선
  - 모델 저장 시 GPU 환경 고려한 분기 처리

## 4. 최종 시스템 특징

### 4.1 주요 기능
- 강화학습 기반 자동 개선
- 멀티 GPU 지원
- 검증 데이터셋 기반 성능 모니터링
- 자동 모델 저장 및 로깅

### 4.2 성능 목표
- Rouge-1, Rouge-2, Rouge-L 평균 50점 이상
- 과적합을 허용하여 최대한의 성능 도출

### 4.3 모니터링 및 로깅
- 에포크별 Rouge 점수 기록
- 모델 개선 과정 상세 로깅
- 최고 성능 모델 자동 저장
